# Contributing

Thank you for your interest in the Smart Traffic Management System project.

## How to Contribute

1. Fork the repository.
2. Create a branch for your proposed change.
3. Make a focused change and describe its purpose.
4. Test your changes where possible.
5. Submit a pull request with a clear summary.

## Code Guidelines

- Use descriptive variable and function names.
- Follow standard Python formatting conventions.
- Add comments when they clarify non-obvious logic.
- Keep hardware-specific code separate from Python modules.
- Document known limitations and testing status honestly.

## Testing

Before submitting changes, run relevant software tests and verify any hardware changes with a low-voltage tabletop prototype.

Do not claim a feature has passed testing unless the test has actually been performed.

## Safety

This project is intended for educational and prototype use only. Contributions must not encourage connecting experimental code to real public-road traffic signals.
