# Traffic Simulation

## Overview

This directory is reserved for a future traffic simulation component using SUMO (Simulation of Urban MObility).

The goal is to explore traffic flow and compare fixed-time signal control with a basic demand-based signal strategy in a simulated environment.

## Planned Work

- Set up a compatible SUMO road network and traffic demand.
- Configure two or more traffic approaches.
- Define traffic-light phases.
- Implement a simulation controller.
- Compare traffic waiting times and queue lengths under different signal strategies.
- Record results and document the simulation configuration.

## Requirements

- SUMO installed and configured locally.
- A compatible SUMO network and route files.
- Correct traffic-light phase indices.
- A tested controller compatible with the selected network.

## Current Status

The simulation has not yet been validated. A working network, route files, and measured results must be added before reporting simulation outcomes.

## Safety

This simulation is for educational evaluation only. It must not be used to control real public-road traffic signals.
