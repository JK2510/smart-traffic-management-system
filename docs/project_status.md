## Important Limitations

The repository contains prototype code and documentation. The presence of a file does not mean its functionality has been tested.

The current Arduino sketch uses fixed timing. The Python vehicle detector and traffic logic have not yet been demonstrated as an integrated, real-time traffic-control system.

This project is for educational use only and must not be connected to real public-road traffic signals.
